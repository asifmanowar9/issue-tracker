🚀 QUICK START

1. Install dependencies:
   npm install

2. Set up environment:
   Create .env.local with:
   NEXT_PUBLIC_SUPABASE_URL=your_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key

3. Run development server:
   npm run dev

4. Open browser:
   http://localhost:3000
